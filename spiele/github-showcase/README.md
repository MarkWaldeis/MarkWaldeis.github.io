## 🌸 Die Top-Highlights im Cartoon- & Everdale-Stil

### 1. [Marchlands (Godot 4)](projects/23_marchlands_medieval_village_godot.md) (1★, Open Source)
- **Was es ist:** Ein mittelalterliches Dorf wie aus *Tiny Glade* oder *Everdale*.
- **Besonderheit:** Straßen werden nie gebaut – Bürger laufen Trampelpfade dynamisch ins Gras (*Wear Field Shader*).

### 2. [Cheoma (Three.js)](projects/24_cheoma_procedural_joseon_village.md) (1★, MIT)
- **Was es ist:** Malerisches traditionelles Bergdorf mit Ghibli-artiger Beleuchtung, Ziegeldächern und Reisterrassen im Browser.

### 3. [TownBuilder (Unity)](projects/25_town_builder_townscaper_unity.md) (32★, MIT)
- **Was es ist:** Exakte technische Reproduktion von Oskar Stålbergs *Townscaper* in Unity via Marching Cubes und Wave Function Collapse.

### 4. [Zelda Wind Waker Web (Three.js)](projects/31_zelda_wind_waker_threejs.md) (192★, Open Source)
- **Was es ist:** Das Große Meer aus *Wind Waker* im Browser mit King of Red Lions Segelsteuerung und Toon-Wasser-Shader.

### 5. [OdysseyLike (Godot 4)](projects/32_odyssey_like_mario_cappy_godot.md) (4★, Open Source)
- **Was es ist:** Die komplette akrobatische Bewegungsphysik aus *Super Mario Odyssey* (Cappy-Wurf, Mützensprung, Hechtsprung) in Godot 4.
