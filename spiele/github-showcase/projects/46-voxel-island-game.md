# Voxel Island Game

> **⭐ Stars:** 5 | **Sprache:** JavaScript | **Lizenz:** MIT
> **Engine:** React + Three.js + WebGL | **Kategorie:** 🏙️ Cozy City & Town Builder

## Beschreibung

Browser-based 3D voxel island sandbox. Place terrain, buildings, nature blocks. Real-time HUD, auto-save, performance tracking. Low-poly island builder.

## Warum visuell ansprechend?

Colorful voxel blocks, island setting, cute low-poly trees and flowers, relaxing sandbox building.
