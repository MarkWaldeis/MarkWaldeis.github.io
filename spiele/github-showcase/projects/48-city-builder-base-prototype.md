## Beschreibung

Simple Unity city builder prototype with road placement, building grid, procedural road mesh. Clean code, great learning resource for city-builder mechanics.

## Warum visuell ansprechend?

Clean grid-based road system, procedural mesh generation, simple but functional city-building UX.
