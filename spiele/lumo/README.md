# Lumo's Skybound Quest

Ein vollständiges, handgezeichnetes Jump-'n'-Run für den Browser – ohne Build-Schritt oder externe Spiel-Engine.

## Spielen

`index.html` im Browser öffnen. Für zuverlässiges Laden der Webfont kann das Verzeichnis alternativ über einen lokalen Webserver geöffnet werden, zum Beispiel:

```sh
python -m http.server 8080
```

Danach `http://localhost:8080` aufrufen.

## Steuerung

- **A / D** oder **Pfeiltasten**: Laufen
- **W / Leertaste / Pfeil hoch**: Springen
- **Shift**: Sprinten
- **Esc / P**: Pause
- Auf Touch-Geräten erscheinen Bildschirmtasten

## Inhalt

- Drei nahtlos verbundene Biome mit mehrschichtigem Parallax, Vordergrund-Silhouetten und Papierkorn-Optik
- Präzise Plattform-Physik mit Coyote-Time, Sprungpuffer und variablem Sprung
- Bewegliche Plattformen, Stachelfallen und vier Gegnertypen inklusive Endboss
- Fünf Sonnensterne, Münzen, Lebensfunken und Checkpoints
- Schwebende Punktetexte, Hitstop, Bildschirmeffekte, Partikel und synthetisierte Musik
- Titelbildschirm, Pause, Game Over und Siegsequenz mit Rangwertung
