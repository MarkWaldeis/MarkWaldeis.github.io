# Lumina: Chronicles of Aether 🌟

Ein vollständig von Grund auf entwickeltes, hochdynamisches 2D-Jump-'n'-Run im **Neo-Fantasy & Cyber-Biolumineszenz**-Stil für den Browser.

---

## 🎮 Spielen & Starten

Das Spiel benötigt **keinerlei Installationsschritte** oder externe Abhängigkeiten.

1. **Option A (Direktstart)**: Einfach die Datei [`index.html`](file:///C:/Users/Mark%20Waldeis/Desktop/KI%20Projekte/lumina-quest/index.html) mit einem beliebigen modernen Browser (Chrome, Edge, Firefox, Safari) per Doppelklick öffnen.
2. **Option B (Lokaler Server)**:
   ```bash
   python -m http.server 8080
   ```
   Anschließend `http://localhost:8080` im Browser aufrufen.

## ✨ Features & Neuerungen gegenüber dem Original

- **4-Schichtiges Parallax-Rendering & Biolumineszenz**:
  - Dynamische Lichtkegel (`lighter` Bloom), schwebende Sporen, God-Rays und leuchtende Kristallarchitektur.
- **Erweitertes Akrobatik-Move-Set**:
  - **Wall-Jumps**: Klettere hohe vertikale Schächte hinauf.
  - **Air-Dash**: Überwinde weite Abgründe mit holografischen Phantom-Schatten.
  - **Lichtflügel-Doppelsprung**: Schwinge dich mit funkelnden Energieflügeln in die Höhe.
  - **Ground-Pound**: Schlage mit hoher Wucht auf den Boden, um Schockwellen auszulösen.
- **3 Detaillierte Biome**:
  1. **Biolumineszenter Hain**: Leuchtpilz-Bouncer, schwebende Plattformen, Sporen-Gegner.
  2. **Kristallhöhlen**: Dampf-Geysire (Aufwinde), Amethyst-Pfeiler, Laser-Drohnen.
  3. **Himmels-Zitadelle**: Rotierende Barrieren, Schild-Wächter und die Arena des Oberherrn.
- **Epischer 3-Phasen-Bosskampf (*Aetheris*)**:
  - Phase 1: Wuchtige Bodenschläge & Sturmangriffe.
  - Phase 2: Rotierende Laserstrahlen & Geister-Beschwörungen.
  - Phase 3: Enraged Overdrive-Modus mit erhöhter Geschwindigkeit und Schockwellen.
- **Polyphones Web Audio Synthwave-Soundsystem**:
  - Dynamisch arrangierte Mehrspur-Musik für jedes Biom, harmonische Shard-Klangfolgen und wuchtige Hitstop-SFX.
- **Apple "Liquid Glass" UI & Lokale Trophäen**:
  - Milchglas-Menüs, Achievements-System und lokale Highscores.
